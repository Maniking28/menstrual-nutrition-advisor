# Menstrual Nutrition Advisor

**Personalized Dietary Guidance Framework for Menstrual Symptom Alleviation Based on Generative Data and Interpretable Machine Learning**

## 📌 Overview

This system predicts six personalized nutritional needs from self-reported menstrual symptoms and lifestyle factors:

| Nutritional Need | Description |
|------------------|-------------|
| Iron | For heavy bleeding and fatigue |
| Magnesium | For cramps and mood swings |
| Hydration | For bloating and water retention |
| Anti-inflammatory | For pain and inflammation |
| Low Sugar | For sugar cravings and mood swings |
| Hormone Balance | For cycle-related mood changes |

### Key Results

| Metric | Value |
|--------|-------|
| Average Accuracy | **85.4%** |
| Range | 83.7% (Low Sugar) - 86.0% (Hormone Balance) |
| ROC-AUC | 0.92 |
| Cross-validation Std | < 0.5% |
